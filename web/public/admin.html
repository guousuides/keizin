受付

締切を押した瞬間のオッズが確定オッズです。 受付中は誰かが賭けるたびに全員のオッズが動きます（本物のパリミュチュエル方式と同じ）。 レースが始まる直前に締め切ってください。締切後は参加者側の取消もできなくなります。

🏁 着順を入れる

● 未保存
1〜3着の3つが埋まった瞬間に、精算とチーム順位が動きます。 途中まで入れた状態では判定は保留のまま（フライング防止）。4着以下は払戻に関係しないので欄がありません。

🔄 次のレースへ（持ち点を繰り越す）

着順を入れてからこれを押してください。 各チームの残高（開始pt ＋ 収支 ＝ 払戻ぶんを含む）がそのまま次のレースの持ち点になります。 購入と着順は消えますが、出走馬・チーム・設定・持ち点は残ります。 消す前に data/archive/ に丸ごと保存するので、後から見返せます。

着順が未入力のまま押した場合は繰り越しません。 全馬券が「不的中」で精算されて全員が賭けたぶんだけ損する形になってしまうので、 そのレースを無かったこと（賭け金は返却）にして持ち点を据え置きます。 レースが中止になったときはこれで大丈夫です。

💰 チームの持ち点（繰越）

● 未保存 — 「持ち点を書き換える」を押してください
いま各チームがこのレースを何ptで始めたかです。ふだんは触る必要がありません （「次のレースへ」を押せば自動で繰り越されます）。 着順を入れ間違えて精算してしまった等のときだけ、ここで直接直してください。
受付中に下げると参加者の残高が減ります。すでに購入した点数より少ない値にすると残高がマイナスになるので、 その場合は購入の取消（⑤タブ）を先にしてください。
「全部リセット」は繰越と全レースの履歴を消して、全チームを初期持ち点に戻します（企画のやり直し用）。

🐴 出走馬（代表者）

● 未保存 — 「出走馬を保存する」を押してください
ここに6人の名前を入れて「出走馬を保存する」を押すと、参加者の選択肢に出るようになります。 名前を空にするとその馬は出走しなかった扱いになります（選択肢から消えます）。 ひとことコメントは参加者のオッズ表に小さく出ます（「腕相撲最強」とか）。 受付開始後に名前を変えると、既に買われた馬券が集計から外れますので、事前に確定させてください。

● 未保存 — 「チームを保存する」を押してください
参加者はこの一覧からチーム名を選んで買います（パスワードなし）。 1レース目の持ち点は全チーム共通で、③設定の「初期持ち点」です。 2レース目以降は前のレースの残高（払戻を含む）を引き継ぎます。 途中で増やしたチームは初期持ち点から始まりますので、 すでに何レースか進んでいる場合は①進行タブの「チームの持ち点」で調整してください。 チーム名を後から変えると別チーム扱いになり、繰越が引き継がれない点にも注意してください。

⚠ 三連系の注意（読んでから係数を決めてください）

「単純積」方式は期待払戻が約180%になります。 6人が完全に横一線（p = 1/6）のとき——
・三連単 … 当たる確率 3!/6! = 1/120、倍率 6×6×6 = 216倍 → 期待払戻 1.80
・三連複 … 当たる確率 3!3!/6! = 1/20、倍率 216÷6 = 36倍 → 期待払戻 1.80

O_i×O_j×O_k = 1/(p_i p_j p_k) は「3回とも6人から引き直す」計算で、 1着に決まった人は2着になれない（母数が減る）ぶんを織り込めていないためです。 しかも倍率は固定ではなく、買う馬によって 1.46〜2.44倍と揺れます（人気馬で固めるほど大きい）。

対処（好きなものを）
(a) 何もしない … 派手な配当が出て盛り上がる。企画としてはこれもアリ
(b) 三連単係数・三連複係数を 0.5〜0.6 に下げる … 手っ取り早い
(c) 三連系方式を Harville補正 にする … 1着 p_i → 2着 p_j/(1−p_i) → 3着 p_k/(1−p_i−p_j) と正しく条件付けした確率の逆数を使う。 期待払戻がちょうど100%になります
複勝は「穴馬買い」が数学的に得です。 a = 1/3 で100%還元になるのは6人が横一線のときだけ。人気が偏ると——
p=0.50（大本命）→ 期待払戻 61% ／ p=0.167（横一線）→ 100% ／ p=0.04（大穴）→ 334%。
3着以内に入る率は100%で頭打ちなのに a × O_i は p が小さいほど伸び続けるためです。 大穴に賭ける動機ができるので、企画としてはむしろ健全だと思います。気になるなら控除率を上げてください。

📊 オッズ内訳

馬単勝から複勝から(×a)三連単から三連複から 合計 A_i素 O_i単勝複勝人気 p_i
各列が「どの券種からいくら流れ込んだか」です。 単勝はそのまま、複勝は a 倍、三連単は1着指名に1/2・2着に1/3・3着に1/6、 三連複は3人に1/3ずつ。重みの合計が必ず1になるので ΣA_i がそのまま賭け金の総額と一致し、Σ(1/O_i) = 1 が成り立ちます。 だから p_i = 1/O_i を「その人が1着になる想定確率」としてそのまま使えます。
例外：1票も入っていない人は O_i がオッズ上限で頭打ちになるので、その人だけこの関係が崩れます （人気 p_i = A_i ÷ ΣA_i の方は 0% になるだけで、合計は常に100%です）。

「適用オッズ」は今の賭け金から計算した値です。受付中は動き、締切後は固定されます。 判定は着順が3つ埋まってから出ます。取消は押し間違いの救済用で、消すとオッズが再計算されます。

👑 チーム順位（このレース）

順位チーム開始pt購入数使用pt払戻pt 収支残高残り持ち点
収支 = 払戻 − 使用、残高 = 開始pt + 収支、 残り持ち点 = 開始pt − 使用（まだ賭けられる額）。 順位は残高の多い順（同点は同順位）。着順が3つ埋まるまで順位は出ません。
開始ptは前のレース終了時の残高です。1レース目と途中参加のチームだけ初期持ち点になります。 繰越しているので、残高がそのまま通算成績です。
